# Чат

Чат — основное рабочее пространство, где вы общаетесь с ассистентом.

## Создание чата

- Используйте кнопку **+** во вкладке менеджера чатов.
- У каждого чата свой **профиль** (настройки), **история** и **память**.
- Чаты хранятся в локальной базе данных и переживают перезапуск приложения.

## Отправка сообщений

Введите сообщение в поле ввода и нажмите **Enter**. Ассистент отвечает текстом,
вызовами тулов и markdown.

> [!NOTE]
> Можно упомянуть конкретного агента через `@имя-агента`, чтобы направить сообщение ему.

## Вложения

- **Изображения** можно прикреплять — их опишут vision-модели.
- **Документы** (PDF, DOCX, PPTX) читаются инструментами работы с документами.

См. также: [Агенты](chat/agents.md), [Тулы](tools.md), [Память](chat/memory.md).
