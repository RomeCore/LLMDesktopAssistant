# Chat

The chat is the main workspace where you talk to the assistant.

## Creating a chat

- Use the **+** button in the chat manager tab.
- Each chat has its own **profile** (settings), **history** and **memory**.
- Chats are stored in a local database and persist across sessions.

## Sending messages

Type your message in the input box and press **Enter**. The assistant replies with
text, tool calls and markdown.

> [!NOTE]
> You can mention a specific agent with `@agent-name` to direct the message to it.

## Attachments

- **Images** can be attached and described by vision models.
- **Documents** (PDF, DOCX, PPTX) can be read with the document tools.

See also: [Agents](chat/agents.md), [Tools](tools.md), [Memory](chat/memory.md).
